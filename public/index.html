Render an HTML artifact, leave inline comments, share the link. Agents can read and reply via the API.

    Agent API

    Each page exposes a JSON API for agents to read and act on comments:

    GET    /api/pages
GET    /api/pages/:id
GET    /api/pages/:id/comments?status=open
POST   /api/pages/:id/comments/:cid/replies   { text, author? }
PATCH  /api/pages/:id/comments/:cid           { resolved: true }
DELETE /api/pages/:id/comments/:cid
