html-comments

Browse HTML files in …. Pick one to read and leave inline comments.

Files

Agent API

Files are identified by their path relative to the HTML root, passed as ?path=.

GET    /api/tree
GET    /api/file?path=foo/bar.html
GET    /api/file/comments?path=foo/bar.html&status=open
POST   /api/file/comments?path=foo/bar.html             { anchor, text, author? }
POST   /api/file/comments/:cid/replies?path=foo/bar.html { text, author? }
PATCH  /api/file/comments/:cid?path=foo/bar.html         { resolved: true }
DELETE /api/file/comments/:cid?path=foo/bar.html
