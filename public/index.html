Agent CLI

Use extension-free document paths like foo/bar. Commands return structured JSON with the next action.

export HTML_COMMENTS_URL='…'

html-comments                              # review inbox
html-comments list --status open
html-comments show foo/bar --content
html-comments poll --path foo/bar --lease 300
html-comments reply foo/bar <comment-id> "What changed" --resolve
html-comments ack <review-id> <lease-id>
html-comments publish artifact.html --to foo/bar.html

Set HTML_COMMENTS_TOKEN too if this server requires a bearer token. Poll claims queued feedback; acknowledge only after every comment is complete.
