Agent API

Files are identified by their extension-free path relative to the HTML root, passed as ?path= (real filenames work too).

GET    /api/tree
GET    /api/file?path=foo/bar
GET    /api/file/comments?path=foo/bar&status=open
POST   /api/file/comments?path=foo/bar             { anchor, text, author? }
POST   /api/file/comments/:cid/replies?path=foo/bar { text, author? }
PATCH  /api/file/comments/:cid?path=foo/bar         { resolved: true }
DELETE /api/file/comments/:cid?path=foo/bar

Upload files

Publish .html, .md, or image files. Re-uploading to the same folder and name updates the page — its link and comments stay put.
